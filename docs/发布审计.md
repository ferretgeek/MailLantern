# Mail Lantern v1.0.2 发布审计

审计日期：2026-08-09
范围：私人原件边界、独立公开重建、全部可达历史与标签、依赖、界面、图片、文档、Release 与 GitHub 设置。

## 结论

- 私有邮件 API、JWT、凭据文件、批量注册与账号自动化均未进入公开项目；公开能力只使用固定的 Apple 官方 iCloud IMAP、验证 TLS 与只读 `INBOX`。
- 58 项测试、Ruff、Bandit、pip-audit、Wheel/sdist、隔离安装与容器门禁通过。
- 桌面与 390×844 移动视口已实测；四套全局主题、深灰 `#17191d`、隐私遮罩、复制与清空状态完整。
- SVG、PNG、ICO 收藏图标、1280×720 实际界面图与 1280×640 社交封面均无私人信息或图片元数据。
- Gitleaks 与 TruffleHog 对公开新鲜克隆的完整历史及全部标签均为 0。

## 历史清理

最终复扫命中的 5 条结果都是以 `test_` 开头、长度恰好匹配 Lob 测试密钥的 Python 测试函数名，不是真实秘密。为让第三方扫描无需人工解释，相关名称及全部可达历史已重写。不可变 `v1.0.0`、`v1.0.1` 标签按 GitHub 规则永久退役，支持版本从 `v1.0.2` 继续。

私有回滚 bundle 与删除前 Release 元数据仅保存在 `资料/安全修复备份/`。公开分支、标签与普通全量克隆不再引用旧提交；GitHub 对不可变发布保留的证明或缓存不属于普通 Git 可删除范围。
